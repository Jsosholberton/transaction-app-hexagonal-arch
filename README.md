# FullStack Application

This is a fullstack web application built with NestJS (backend) and React.js with Redux (frontend).

## 🚀 Technologies

Backend: NestJS, TypeORM, PostgreSQL, AWS Lambda, Hexagonal Architecture, Terraform

Frontend: ReactJS, Vite, Redux Toolkit, TailwindCSS, React Router

## 📂 Structure

project-root/
├── backend/    # API, DB access, infrastructure
├── frontend/   # SPA using React and Redux

Each folder contains its own README:

[Backend README](https://github.com/Jsosholberton/transaction-app-hexagonal-arch/blob/main/backend/README.md)

[Frontend README](https://github.com/Jsosholberton/transaction-app-hexagonal-arch/blob/main/frontend/README.md)

## 📚 Features

Product listing and detail pages

Transaction creation and status update

Search transactions by customer email
